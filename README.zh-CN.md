# 上班鼓励器 · Work Cheer

中文 · [English](README.md)

放在桌面右下角的上班计价小窗。收入大字显示，其他文字小小的。

![上班鼓励器](preview-zh.png)

## 功能

- 默认 360 × 280，可拖动窗口缩放，最小 160 × 100，也可铺满桌面或全屏。
- 支持月薪制和日薪制，自定每日工作小时数；月薪制工作日默认 22 天，也可手填。
- 实时计价、暂停／继续、按实际时长停止计费、手动下班领全天工资。
- 拖动进度条补卡，按分钟调整今日已上班时长。
- 日历查看每月打卡状态、时长和记录收入。
- 设置中切换中文／English；界面、菜单、日历、20 条随机台词均支持双语。
- 所有薪资和打卡数据只保存在本机，无需账号、联网或上传。

## 安装

在本仓库 [下载 Work-Cheer-Mac.zip](Work-Cheer-Mac.zip)，解压后将应用拖入「应用程序」。支持 macOS 12 及以上、Apple 芯片和 Intel Mac。

应用为本地签名构建，**未经 Apple 公证**，其他 Mac 首次打开可能被系统拦截。本项目不含 Apple 开发者证书。

## 使用

在「设置参数 → 界面语言」切换中英文。选择薪资制度，填写工资和每日工作小时数后开始上班。暂停不计费，停止计费保留实际收入，手动下班按一天工资结算。拖进度条可补今天的工作时长；暂停或停止状态不会因拖动而自动开始计费。迷你模式的其他操作可从菜单栏「¥」找到。

月薪制日薪 = 月薪 ÷ 每月工作日；时薪 = 日薪 ÷ 每日工作小时数。切换语言不会转换币种，均使用人民币估算，不替代实际薪酬核算。

关闭窗口只会隐藏小窗。退出应用后，运行中的计时再次打开会补算经过的时间（上限为每日工作时长）；不希望累积时请先暂停或停止。修改参数只重算当前面板对应记录，其他历史保留。跨午夜记录归入开始日期；面板仍停留在往日时，拖动补卡会保留旧记录并创建今天的记录。

## 从源码打包

在 Mac 安装 Apple Xcode Command Line Tools，然后运行：

```sh
bash build.sh
```

脚本生成 Apple 芯片与 Intel 通用应用，完成本地签名及中英文自检，输出 `build/Work-Cheer-Mac.zip`，无需第三方依赖。

`*.swift` 为源码，`zh-Hans.json` 与 `en.json` 为双语配置，`InfoPlist.*.strings` 配置双语应用名。本机工资和记录保存在 `local.workcheer.meter` 偏好域，未纳入仓库。

# 上班鼓励器

[English](README.en.md)

**忍忍，别和钱过不去。**

输入工资，点「开始上班」，桌面上就会多一个小窗口，显示今天已经赚了多少钱。

不想上班的时候，看两眼。

**[下载 Mac 版](https://github.com/CUICAN-fafa/work-cheer/raw/refs/heads/main/Work-Cheer-Mac.zip)**

免费，无需注册。支持 macOS 12 及以上，Apple 芯片和 Intel 都能用。

![上班鼓励器](preview-zh.png)

## 能做什么

- 工资按月发、按天算，都能用。
- 累了可以暂停，忘记开计时可以拖进度条补上。
- 点「停止计时」，保留当前金额。点「下班」，按一天工资记。
- 窗口想放多大放多大，缩小挂在桌面角落也行。
- 在「上班记录」里能翻到之前的打卡。
- 有 20 条随机台词，不想看这句就换一句。
- 工资只存在自己电脑上。界面支持中文和英文。

## 怎么用

下载并解压，把「上班鼓励器.app」拖进「应用程序」。

打开后点「修改工资」，填好工资和每天上班的小时数，再点「开始上班」。工资按月发的话，每月默认算 22 天，也可以自己改。

小窗关掉了，可以从菜单栏的「¥」找回来。

## 几件事说清楚

**这里显示的是估算金额，不是实际到账。** 月薪除以每月上班天数得到日薪，日薪再除以每天工时得到时薪。按日薪算的，直接填一天多少钱就行。

**关窗口不等于暂停。** 如果还在计时，关掉应用再打开，会补算这段时间，最多算到你设置的每日工时。想停就先点「暂停」或「停止计时」。

改工资只会重算当前这次上班的金额，以前的记录不变。点「重新开始」，上一次的记录也会留下来。跨午夜的打卡记在开始那天；补今天的卡不会覆盖往日的记录。

**当前安装包还没做 Apple 公证。** 首次打开，Mac 可能会提示无法验证开发者。目前只有 Mac 版。

## 自己打包

Mac 装好 Xcode Command Line Tools 后，运行：

```sh
bash build.sh
```

安装包会生成在 `build/Work-Cheer-Mac.zip`。脚本会检查中英文配置、构建 Apple 芯片与 Intel 通用版、完成本地签名并运行自检。

源码是仓库里的 `*.swift` 文件。中英文文案在 `zh-Hans.json` 和 `en.json`，应用名在 `InfoPlist.*.strings`。本机工资和记录保存在 `local.workcheer.meter` 偏好域，不在仓库里。
